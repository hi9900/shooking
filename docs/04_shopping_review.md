# 쇼핑몰 연동 리뷰

## 고객사 요구사항

1. 페이지 연동: 상품 목록, 장바구니, 결제 등 모든 페이지에서 이동이 자연스럽게 이루어져야 합니다.
  예를 들어, 상품 목록에서 장바구니로 이동하면서도 사용자가 선택한 상품 데이터가 유지되어야 합니다.
2. 데이터 일관성: 페이지 간 이동이 있어도 데이터가 일관되게 유지되어야 합니다.
  상품 목록에서 장바구니에 상품을 담았을 때 다른 페이지에서도 그 상품이 장바구니에 담겨 있음을 명확히 보여주는 것처럼
3. 상세 페이지 추가: 상품을 클릭했을 때 나타나는 상세 페이지에서는 상품에 대한 상세 정보와 관련 상품 등을 보여주어야 합니다.
  관련 상품은 같은 브랜드의 상품을 보여주시면 됩니다. 피그마 시안에, 브랜드별로 관련 상품을 추가해두었으니 확인해주세요.
4. 테스트 URL 제공: 작업하시면서 중간에 테스트 URL을 제공해주세요.

## 요구사항에 따른 기능 동작 확인

### 1. 페이지 연동 및 이동 (라우팅)
- **기본 이동:** 상품 목록, 장바구니, 결제 페이지 간의 이동이 새로고침 없이 정상적으로 이루어집니다.
- **뒤로가기:** 모든 하위 페이지(상세, 결제 등)에서 헤더의 '뒤로가기' 버튼 클릭 시, 이전 페이지로 정상 이동합니다.
- **상세 페이지 진입:** 상품 목록에서 개별 상품을 클릭했을 때, URL이 `/product/:id` 형태로 동적 라우팅이 되며 해당 ID의 데이터를 로드합니다.

### 2. 데이터 일관성 

- **장바구니 뱃지:** 상품을 장바구니에 추가/제거할 때, 헤더의 장바구니 아이콘(뱃지)이 현재 페이지와 관계없이 실시간으로 수량을 업데이트하여 보여줍니다.
- **상태 유지:** 장바구니에 상품을 담은 후 다른 페이지(예: 상품 목록)로 이동했다가 다시 돌아와도, 담았던 상품 데이터가 그대로 유지됩니다.
- **금액 일관성:** `CartContext`에서 계산된 '총 금액'(`total`)이 장바구니 페이지와 결제 모달(혹은 페이지)에서 동일하게 표시됩니다.
